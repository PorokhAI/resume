# Resume — Alexander Porokhin

Static resume website, ready for GitHub Pages and Vercel.

## Local preview

Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the project as a static site; no build command is required.
4. Deploy.

## GitHub Pages

Enable Pages for the repository and publish from the branch containing `index.html`.

## PDF

The **Печать / PDF** button opens the browser print dialog. Choose **Save as PDF** to create an up-to-date PDF version.
